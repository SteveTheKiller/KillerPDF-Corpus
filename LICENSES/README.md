# Licensing

The corpus combines materials from multiple upstream projects. There is no single
license that replaces the licenses of the individual source collections.

- veraPDF corpus files retain the Creative Commons Attribution 4.0 International
  license and their upstream attribution requirements.
- qpdf, Apache PDFBox, and Mozilla PDF.js files retain the Apache License 2.0.
  The complete license text is included as `Apache-2.0-qpdf.txt`.
- Apache PDFBox attribution is preserved in `NOTICE-PDFBox.txt`.
- PDFium files retain the BSD 3-Clause license in
  `BSD-3-Clause-PDFium.txt`.
- PDFium's imported JBIG2 fixtures retain the BSD 2-Clause license in
  `BSD-2-Clause-PDFium-JBIG2.txt`.
- PDFium's imported Skia fixtures retain the BSD 3-Clause license in
  `BSD-3-Clause-PDFium-Skia.txt`.
- PDFium's imported TCPDF fixtures retain the GNU Lesser General Public
  License version 3 or later. The upstream notice is in
  `NOTICE-PDFium-TCPDF.txt`, and the complete license text is in
  `LGPL-3.0-TCPDF.txt`.
- The Synthetic PDF Testset for File Format Validation retains the Creative
  Commons Attribution-ShareAlike 4.0 International license in
  `CC-BY-SA-4.0-Synthetic-PDF-Testset.txt`. Attribution is recorded in
  `SOURCES.md`.
- Accepted OpenPreserve Format Corpus files retain CC0 1.0 Universal, except for
  its Synthetic PDF Testset files, which retain CC BY-SA 4.0. The complete CC0
  text is in `CC0-1.0-OpenPreserve-Format-Corpus.txt`. Fifty GovDocs files with
  insufficient redistribution documentation are excluded from the accepted set.
- Accepted iText files retain the GNU Affero General Public License version 3 or
  later. The complete license is in `AGPL-3.0-or-later-iText.txt`, and upstream
  notices for included test resources are preserved in `NOTICE-iText.txt`. Ten
  Adobe or explicitly third-party PDFs without documented redistribution rights
  are excluded from the accepted set.
- The PDF Association Stressful PDF Corpus is an external benchmark overlay and
  is not redistributed in KillerPDF Corpus release archives. Its files retain the
  rights and restrictions of their original issue-tracker attachments.
- The Altona Test Suite and Ghent PDF Output Suite are external benchmark overlays.
  Their files are obtained from the official publishers and are not redistributed
  in KillerPDF Corpus release archives.
