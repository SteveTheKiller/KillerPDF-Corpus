The corpus combines materials from multiple upstream projects. There is no single
license that replaces the licenses of the individual source collections.

- veraPDF corpus files retain the Creative Commons Attribution 4.0 International
  license and their upstream attribution requirements.
- qpdf files retain the Apache License 2.0. The complete upstream license is
  included as `Apache-2.0-qpdf.txt`.
- Future sources will be documented separately in this directory and in
  `SOURCES.md`.

Original KillerPDF Corpus scripts are provided under the MIT License. Original
documentation and manifests are provided under Creative Commons Attribution 4.0
International.

Importing a file into this project does not change its copyright or license.
